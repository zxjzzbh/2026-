# 扩展板语音修订（2026-11-20）

本车用户确认喇叭通过扩展板连接。既有项目中的 autonomy_audio.py / speak_parking.py 使用 I2C1、0x40 TTS，中文使用 GB2312，整句单报文发送。2026-11-20 在车辆 idle、执行器关闭时，已向该通道发送“语音测试”，用户确认听到且内容清楚，音量为 8。

本版在此前 f6cbe65e 版本基础上只修正播报通道：announcement_backend=i2c_tts，announcement_volume=8。斑马线确认停稳时发起播报，10 秒停车包含播报，不在播完后再加 10 秒。红绿灯、25 秒超时转避障、巡线和停车逻辑保持此前版本。

cpp/tools/announce_i2c.py 仅操作 /dev/i2c-1 的 0x40；不打开运动串口。整句按既有协议在一次原始 I2C 写入中发送，应用上限 64 字节，不按 SMBus 32 字节拆成多段，以免停顿或漏句。由 C++ 有时限的独立子进程调用，失败不会阻塞视觉控制。扩展板每次斑马线阶段最多发送一次，避免“写入已经成功、完成反馈不明”导致重复播报。WAV 后端作为可配置备用保留。

本车观测到状态字 0x4A、0x41，但未验证其对应明确的 busy/idle 及真实播报结束。因此正常发送后网页显示“已发送到扩展板”，日志 announcement_status=submitted，不把写入成功冒充自动确认播放结束。发送失败显示 failed。离线回放仍为 simulated，不打开 I2C 或声卡。

目前已确认测试短句可以实际出声；正式整句仍需现场核对完整内容和播放时长。语音发送不延长停车计时，原有 10 秒窗口和运动安全输出不受 I2C 播放进程影响。
