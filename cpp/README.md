# C++ 比赛入口

本目录编译一键测试版使用的 C++ 比赛程序。网页测试、模块来源、构建、相机重连和手动终止见[根目录运行说明](../README.md)。

`src/main.cpp` 按比赛阶段调用 `algorithms/hybrid.py` 中的旧版斑马线、红绿灯和双锥桶模块。新版常规巡线、发车和停车继续由 C++ 实现。`config/race.json` 使用 H65 看地面、USB2.0 主摄作补充，控制器统一输出转向与油门。

`docs/` 保存 11 月 19 日基础版本的标定、来源和历史复核记录。其中旧 C++ 红绿灯、斑马线和绕障实现的描述与单元测试用于追溯。当前组合程序的选择和验证以根目录说明和 `tests/test_hybrid.py` 为准。
