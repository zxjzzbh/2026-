# 5G 与远程通信

负责蜂窝联网、视频回传、远程操作端、指令传输和连接状态。现有模块具体型号及接入方式待确认。

## 放在这里

- `vehicle_side/`：车端网络与视频服务。
- `remote_side/`：远端控制界面/客户端。
- `configs/`：脱敏配置模板，例如 `frpc.example.toml`。
- `docs/`、`tests/`：部署说明、链路测量及模块验证。

不预先指定网络协议、公网服务器或云服务供应商。写明实际依赖、端口、启动顺序及重连方式，但真实凭证放本地配置。

## 联调边界

远程命令交给 [vehicle](../vehicle/README.md) 仲裁，不直接绕过模式管理输出电机指令。视频回传不能阻塞车端感知，摄像头统一采集分发。

提交时报告网络拓扑、测试网络类型、视频延迟、控制延迟、断连表现和恢复方法。局域网开发测试与 5G 参赛验证必须明确区分。
