# 电脑端车辆控制台入口

本机推荐地址：`http://127.0.0.1:8082/`。这是车端原控制台的 TCP 直连入口，页面、实时画面、控制令牌与心跳均来自车端，不是模拟页面。

## 一键连接

双击桌面 **“一键连接小车”**，或项目根目录的 `connect-car.cmd`。脚本执行 `vision/connect-car.ps1`，依次检查现有 Tailscale、车辆网页与SSH端口、本机8082转发入口，成功后打开默认浏览器；失败时保留窗口并说明当前卡在哪一层。

- 已连接时直接复用，不重复启动转发。
- Tailscale服务停止时尝试启动；客户端处于Stopped时调用不带参数的 `tailscale up` 恢复现有设置。需要登录或服务权限不足时会提示，不更换账号、不自动注册。
- 用有次数／时间限制的Tailscale ping唤起路径；HTTP只发GET并直连，不经过系统HTTP代理，也不修改代理配置。
- 本机转发不存在时后台启动；只有确认进程是当前项目的loopback转发、车端无控制会话时，才重建无响应转发。其他占用端口的程序不会被结束。
- 不发送准备／开始／PWM指令，不修改摄像头、标定、APN、防火墙、Tailscale权限或车端服务。已有控制会话时不自动打开新窗口抢占焦点。
- SSH端口可达只代表TCP可连接，**不代表已认证登录**；脚本不读取或保存SSH密码。
- 小车关机或掉线时，脚本不能代替现场给树莓派和5G模块上电联网；会返回失败，不把本机端口可用误报为小车已连接。

连接结果保存在 `run/connection/*.json`，不保存控制令牌、账号清单或登录URL。仅检查可运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\vision\connect-car.ps1 -CheckOnly -NoOpen
```

`-NoOpen`只是不自动打开浏览器，仍允许修复本机连接；`-CheckOnly`不启动服务、不恢复Tailscale、不启动或结束转发。脚本兼容Windows PowerShell 5.1，相关PS文件使用UTF-8 BOM。只对当前脚本进程采用RemoteSigned执行策略，不修改机器持久执行策略。

2026-10-10实测：起初车端22/8080及本机8082均可达，随后车端链路中断。本机Tailscale执行一次down/up后恢复Running，目标最终报告Online=false，因此本次不能声称已重新连上小车。真实离线分支与CMD启动入口已验证，10项连接控制保护检查及3项TCP转发测试通过；桌面快捷方式目标已核对。小车上线后再次双击即可重新检查。

2026-10-10 排查：车端 `smartcar-preview.service` 为 active/running，直接请求 `100.124.156.117:8080` 返回 200；显式经过电脑 FlClash 的 `127.0.0.1:7890` 代理则超时。Windows 代理例外已有车端 IP，但不足以证明所有外置浏览器都采用相同路径。采用本机入口可让电脑上的转发进程通过普通 TCP 连接车端，不依赖 HTTP 代理。

## 启动

从项目根目录运行：

```powershell
.\vision\run-console.ps1
```

启动器检查 Python 和端口占用，已有同一入口时复用；不会杀死其他占用端口的程序。日志保存在 `run/console-forward/`。

当前电脑额外安装了 Windows 登录启动项“Smartcar Console Forward.lnk”，并在桌面放置“车辆控制台.url”和“恢复车辆控制台入口.lnk”。登录启动项只启动本机转发进程，不启用遥控、不发送 PWM、也不启动斑马线任务。删除该登录启动项即可取消自动运行；这些带本机绝对路径的快捷方式不提交 Git。

## 行为与限制

- 仅监听 `127.0.0.1:8082`，不向局域网或公网开放新端口。
- 只连接既有车端 `100.124.156.117:8080`，不自动探测或控制其他设备。
- 请求与响应按原始字节传输；保留原有 Host/Origin 校验、控制令牌和原车端看门狗，不重试或重放控制请求。
- 车端不可达时显示 503 连接提示；车端恢复后刷新页面即可重新连接，不自动恢复车辆运动。
- 仍需要车端供电、Tailscale 连通和车端服务运行。若浏览器扩展连 `127.0.0.1` 都强制代理，也需要将该地址设为直连。
- `127.0.0.1` 只代表当前这台电脑；其他电脑需要各自运行入口，或直接访问车端地址。

红绿灯采集与标注仍在 `http://127.0.0.1:8091/`，与车辆控制台分开。
