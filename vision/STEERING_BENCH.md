# 前轮转向初始测试

后续正中与初始工作范围校准见 [架空校准记录](BENCH_CALIBRATION.md)。
本文保留最初测试的步骤和当时状态。

转向信号使用 BCM12（物理针脚32），电调信号使用 BCM13（物理针脚33）。
这项测试只输出转向信号，不输出电调信号，也不修改正式控制的校准配置。

2026-10-02，用户确认驱动轮已架空，转向舵机红线接树莓派5V针脚。
供电容量、舵机实际型号和转向机械限位仍未测定。

默认只预览计划，不连接驱动：

```sh
.venv/bin/python -m carvision.steering_bench --output unused --observe
```

实际测试使用 `--run --confirm-5v-pin-wiring --wheels-raised`。
默认先发100毫秒的1500微秒参考脉冲；加 `--observe` 后，在两秒内按
1500→1450→1550→1500微秒渐变，每次变化不超过10微秒，然后关闭脉冲。
1500微秒不是已测量的前轮正中位置，1450/1550也不是转向限位。

驱动仅允许BCM12写入，使用本机PCM定时，独立超时3秒或5秒自动结束。
测试前检查现有引脚占用和欠压；结束后记录脉冲关闭、输入模式、供电状态。
这不能证明供电长期可靠，也不能代替观察实际机械动作。

树莓派记录保存在 `run/steering-reference-20261002-01` 和
`run/steering-observe-20261002-01`；电调型号与停止脉宽未确认，尚未测试驱动轮。
