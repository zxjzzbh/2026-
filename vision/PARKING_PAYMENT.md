# 停车扫码缴费

入口仍为 `http://127.0.0.1:8082/`，新增“停车缴费 · ¥0.01”卡片。直接访问车端时使用原来的 8080 页面。

## 现场操作

1. 让**第二路 H65 摄像头**清楚拍到停车区域的付款码，点击“识别付款码”。软件持续读取第二路；第一路不参与缴费判断。可再次点击“停止识别”结束搜索。
2. 未完整解码时，持续刷新观察画面，**不冻结截图、不开始计时、不锁车**。解码成功后停止搜索并冻结真实二维码图，可点击“放大付款码”供手机微信扫描。多个二维码时先选择正确的一张，核对收款方；检测到方框但未解出内容不算识别成功。
3. 确认四轮已停入规定停车区域且静止，立即点“四轮已停稳 · 开始计时”。本页开始 30 秒提示计时，结束现有控制并锁止新的行驶请求。
4. 队员在微信核对收款方，支付 **0.01 元**，向裁判展示微信支付成功页；然后点击“我已支付0.01元 · 记录回执”。
5. 付款记录会显示是否在本页窗口内报告。“结束本轮记录”解除缴费流程锁止，不会自动准备或启动车辆。

裁判计时依据实际停车时刻。本页从队员点击停稳按钮开始，不是自动检测停车，也不能替代官方计时。切换微信、刷新同一标签页、重复点击开始都不会延长本轮计时。超时仍可记录回执，但会标为迟到；晚点击回执不等同于银行实际付款超时。

若服务中途重启，页面保留“流程中断”锁止，并提示先核对微信结果，再结束旧记录。若原标签页已关闭，可在刷新后的控制台结束旧记录；不要直接重复付款。

## 功能与限制

- 使用现有第二路摄像头采集进程，识别期间暂存未经预览缩小的原始帧并以高质量 JPEG 解码，不重复打开 USB 摄像头、不更改云台姿态或其他视觉模块的预览尺寸。
- OpenCV 定位/解码二维码；原图失败且尺寸允许时增加一次 2 倍三次插值解码尝试。坐标还原到原图后裁剪放大真实图像；解码结果只作为文字显示，不自动打开其中的网址，也不重绘二维码。
- 计时前重新识别会清除旧选择；未解出新码时不保留旧图作为本次识别成功。计时开始后的付款图保持冻结，新的未识别画面不会自动取消正在进行的缴费锁止。只解出一个明确内容时可自动选中，仍由队员在微信核对收款方。
- 锁止覆盖手动遥控、斑马线、红绿灯与锥桶运动入口。已有停车/急停入口保留；支付完成后不会自动行驶。
- 付款由队员使用微信完成。本程序没有微信商户回调或查单接口，`operator_reported_paid` 仅为人工报告，`provider_verified` 始终为 `false`；不自动扣款、判分或宣称到账。
- 本模块处理停车后的缴费操作；四轮入位判断和自动泊车仍由其他模块后续接入，没有用人工按钮伪造传感器证据。

## 实现与运行入口

技术栈沿用 Python、OpenCV、原 HTTP 控制服务、原生 HTML/CSS/JavaScript 和 JSON/JSONL 记录，无 ROS、支付 SDK 或新前端依赖。

车端入口为 `vision/tools/serve_parking_payment.py`，它将原有全部参数转交 `serve_crosswalk_trial.py`，在现有手动/斑马线/红绿灯/锥桶控制栈最外层增加缴费模块。原摄像头进程与串口控制仍由现有入口管理。由现有 `smartcar-preview.service` 启动，不要同时再启动第二份控制服务。

主要文件：

- `src/carvision/parking_payment.py`：二维码截图、固定金额及付款窗口。
- `src/carvision/payment_console.py`：第二路持续识别、原始帧缓存、控制互斥、人工回执、重启恢复。
- `src/carvision/payment_controls.py`：实际控制台卡片和图片接口。
- `tools/deploy_parking_payment.py`：只部署本模块，保留当前已安装的其他控制代码、参数和服务参数；控制未释放时拒绝重启。

本地测试：

```powershell
.\.venv\Scripts\python.exe -m pytest vision/tests/test_parking_payment.py -q
```

车端记录位于 `run/parking-payment-<本轮ID>/`：事件、汇总、选定付款码截图及原始画面。`run/parking-payment-current.json` 用于重启时发现未结束记录。日志不写二维码原文、连接凭据或页面控制令牌；截图本身包含付款码，属于现场原始资料，不提交到 GitHub。

调试时先检查真实图像中二维码是否完整、清晰、无反光且占足够像素；可在不开始计时、不启动车辆的情况下反复点击“识别付款码”。软件测试不会代替实际微信扫码或真实付款验收。
