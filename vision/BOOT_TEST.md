# 开机等待与电脑双击测试

电脑入口在 `pc-launcher/start.cmd`；当前电脑也可使用桌面的“智能车5G测试”快捷方式。
公开版先按 `pc-launcher/使用说明.txt` 配置 SMARTCAR_HOST。入口只等待已有的 Tailscale 连接、建立本机转发并打开网页，不需要 SSH 密码。
车辆上网使用现有 5G 模块；电脑需要联网并保持 Tailscale 在线。

车端为 `tools/serve_boot_test.py`、`carvision.boot_test` 与 `deployment/smartcar-preview.service`。
服务开机启动的是等待页面：不会开机写入舵机或电调，不会恢复旧轮次或旧按键。
只有当前网页明确确认电调关闭，才写入 S4=1500 的零油门并执行 30 秒稳定性检查。
该检查还核验 USB 5G 注册、网络路线、软件哈希、开机标识与供电/温度；不写转向或云台。
随后需要第二次现场确认：电调打开、轮子静止、手移开；程序回读零油门并保存本次开机的真实确认。
此时才创建用户明确选择的控制进程，准备 12 秒后由用户按键驾驶。

2026-10-08 用户明确要求长距离、长时间连续遥控，已报告先前传动卡滞处理完成。
当前模板选择 `ground_continuous_requested_by_user`：不设行驶总时长或单次按住时长限制，
W/S、上下键控制持续前进和倒车，A/D、左右键可与行驶键组合。空格或 Esc 急停。
使用已有固定低档位，直行前建立舵机位置保持。倒车保留 0.3 秒刹车和至少 1.2 秒回零等待。
松开行驶键、失联、切换窗口均停车。5G 持续遥控的输入超时按用户要求设为 500 ms；其他短测与 S3 调试仍为 200 ms。
持续遥控连续 500 ms 未收到新方向消息会停车锁定，迟到消息不会自动恢复行驶。松键和急停收到后立即处理，不等待这 500 ms。
独立进程的 250 ms 看门狗和短输出期限继续生效：
只有新鲜方向消息续接最多 0.2 秒的行驶输出，页面轮询不会延续运动。
持续模式移除原来的 60/600 秒轮次以及 800/810 秒进程总时限；每段输出期限不变。
独立停车进程持续检查供电、开机状态，以及 5G USB 路线和温度。故障不自动恢复运动。
急停后可解除并重新确认启用，无需创建下一轮。旧短测模板仍保留原有限时长行为。
当前开机的倒车和长距离实车效果须现场复测；不会把开放测试记成倒车实测通过。
故障不会自动重开。刷新或重启会清除页面的就绪确认；旧步骤请求不能跨越新的准备阶段。

每次准备产生独立的 `run/boot-tests` 记录，旧中位静止证明不会被复制成新开机的证明。
静态模板 `deployment/boot-test-template.json` 是配置来源，不能作为已确认的实车准备记录使用。
修改已核验的软件后需要重新验证及生成对应软件清单，否则拒绝开始新轮。

Windows 入口使用 Python 标准库和 Tk，不含密码、额外 SSH 库或私人密钥。
它仅绑定 `127.0.0.1:18080`，每条浏览器连接单独转发，不重试或重放断开的控制请求。
重复双击可复用匹配车辆会话的本地转发；端口归属不匹配时明确报错，不关闭其他进程。
等待联网上限为三分钟，超时提示后可以再次双击。

初次部署先确认没有运行中的硬件控制，再备份原开机服务，更新并验证源码、模板与测试。
部署记录应保留原服务和源文件备份。改回原服务可以恢复摄像头预览模式。

## 网页 S3 调试入口

当前等待页可选择“仅 S3 转向调试”，现场确认改为电调关闭、车轮架空。
S3 的准备和确认步骤不打开 UART 或操作 S4；启用后仅 S3 输出。
每次原始 PWM 试调最多 2 秒，本轮 120 秒，可正常结束后再开始。
“结束当前测试，返回模式选择”先停车并清理旧工作进程；清理完成前不接受新方向或模式。
完整操作与数值含义见 `STEERING_PWM.md`。

## 纯 5G 网络检查

车辆默认路由必须走 `usb0`，5G 模块须注册；网线和 Wi-Fi 不能作为同时启用的备用出口。
2026-10-08 现场发现树莓派自动连接 iPhone 热点，已关闭该配置的自动连接和车端 Wi-Fi 无线电。
操作电脑可继续使用 Wi-Fi；此项仅更改车端联网。
某些无线驱动在未关联时仍保留 `carrier=1`，关闭网卡后读 `carrier` 又可能返回 EINVAL。
准备检查与独立停车进程共同先检查 IFF_UP：明确关闭的网卡视为不可用；启用的网卡仍须核对 carrier=0。
无法核验的网卡继续阻止测试，5G 默认路由、温度和停车保护均保留。
以后需要车端 Wi-Fi 维护时可手动打开无线电并连接保存的热点；恢复纯 5G 测试前再关闭车端 Wi-Fi。
