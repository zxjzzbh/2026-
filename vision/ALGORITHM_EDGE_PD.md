# 避障与停车算法修改（2026-10-20）

基线：GitHub 主线 `cdf8d3172089c9d8bb39c1ddea9188a2f85b86a1`。本版只在电脑修改和验证，未部署或驱动车辆，实际通过率、轮角响应与停车精度待实车测试。

参考 [sana-u/smartCar 的 line.cpp](https://github.com/sana-u/smartCar/blob/e4d304e35a71637ca344848858799dbac32bfe45/g5g-new/line.cpp) 和 [qudong.cpp](https://github.com/sana-u/smartCar/blob/e4d304e35a71637ca344848858799dbac32bfe45/g5g-new/qudong.cpp) 的“目标边缘偏移 → 误差 → PD 转向”思路独立实现。保留当前蓝桶识别；不搬用其红色轮廓、55/40 像素偏移、GPIO/PWM 单位、固定计时变道、强制左转/选 B 或按帧位置跳变数桶。

## 绕桶

- `ContinuousConeController` 同时用于原网页持续绕桶和完整流程的锥桶阶段。
- 首次选侧后，同一目标不因位置抖动逐帧换侧；确认第一桶通过后，第二桶在图像间隙可用时优先交错绕行。相机切换只有唯一关联候选才能延续目标，失败不计作通过。
- 目标由锥桶边缘、现有车身图像余量和白线内侧生成；短暂遮挡时保留绕行目标至已有通过证据完成，避免桶尚在车侧就回中。
- 通过计数要求连续的当前侧向净空证据；仅进入画面下沿后消失不计作通过。第二次计数还要求与第一次绕行侧相反，证据不足继续记录为未确认，不冒充完整流程两桶通过。
- 不再对目标做 0.18 秒低通。共享 `ImagePD` 对误差变化率按新鲜帧的实际时间计算并滤波，缓存帧不重复修正。相机坐标或目标改变会重置微分历史。
- PD 基准 `kp=1/0.12, kd=0.18`，微分滤波时间常数 `0.06 s`；这些是本地试验初值，不是实测最优增益。原网页转向增益继续有效。
- 保留 1200 μs/s 转向变化上限，修复 5 Hz 更新只能按 0.1 秒算变化额度的问题。第一次转向输出仍限制额度，输出端点及原油门范围不变。
- 单项仍由操作者结束；完整流程两桶通过后衔接停车搜索。保留原断帧、心跳、独立执行器期限保护。间隙不明确时仍是原有低速尝试模式，会标为不确定，不能当作碰撞保证。

## 停车

- 原网页独立停车仍由 `ParkingEntryController` 执行：寻找已选空位 → 转入 → 回正对齐 → 接近真实远端黄线 → 有限制动 → 连续停稳估计。
- 转向同时使用车位中心的横向误差和远近中心差得到的朝向误差，避免单个目标点居中但车身仍斜着。新增 `guidance_phase`、两类误差及转向策略日志。
- 停车 PD 基准 `kp=1, kd=0.12`，朝向误差权重 `0.45`；转向变化率从 260 改为 600 μs/s，仍限制在右 1350 / 中 1610 / 左 1870。更快的是指令变化，实际舵机响应尚未测量。
- 只有实际关联的远端黄线能触发停车；缺边界不填造车位，蓝挡板占据已选侧仍停止。到停车参考时若车身横向或朝向仍未对齐，制动退出，不报告完成。
- 不改 65/50/25 cm 原始参考、50 cm 黄线转移参考、F/B 有限刹车时序、油门或光流停稳逻辑；黄线参考转移和整车入位仍未实测验证。
- 完整流程保留 `ParkingMission` 的米制路径、标定门控、车身范围及付款入口条件，只在有效停车路径输出端加入 PD 与 600 μs/s 限速。因此默认配置的停车缺项仍会阻止自动入位，独立视觉试验完成不等于完整流程已通过停车。

## 本次验证记录

- Windows、Python 3.12.14、OpenCV 4.11.0、NumPy 2.2.6、pytest 8.3.5，使用 `vision[test]` 声明的依赖：完整回归 **1647 通过、3 跳过**。跳过项为 Unix socket、termios 等 Linux 接口。报告 `run/edge-pd-tests-py312-20261020.txt`。
- 新增覆盖：同桶选侧锁定、两桶交错衔接、缺侧向净空不能数桶、5/20 Hz 指令变化预算、缓存帧、双摄不同时间戳切换、停车朝向偏差及完整流程执行器输出。
- 同一合成小偏差目标下，旧版下一次更新才出现转向，新版首个有效目标帧即产生转向指令。合成固定右车位中，从首个前进指令到转向端点指令由 0.9 s 变为 0.4 s；不包含真实车轮响应时间。
- 原始 46 条锥桶导航观测回放中新旧版均未插入非前进指令，通过估计均为 0，不伪造已通过桶数。新算法会改变真实后续视角，因此固定观测回放不能证明实车路径更好。
- 默认自主检查仍有 18 项准备缺项，完整流程停车仍有 11 项提示。原基线审计中旧 `GroundVisualOdometry` 点对越界异常仍可复现，本轮未修改该旧自主运行路径。

## 首轮实车核对

沿用现有低速档和相机姿态，从转向增益 1.0 开始。先各测一只桶的左/右绕行，再测两桶衔接；停车先分别检查转入和回正，再检查制动停点。每轮只改一个控制因素，保留失败录像。确认重复通过后再另行提速，本版未提高油门。
