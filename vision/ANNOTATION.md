# 第一版 YOLO 标注规范

本队数据格式，预训练候选 YOLOv8n，微调后四类顺序固定：

| ID | 名称 | 框选范围 |
|---|---|---|
| 0 | cone | 单个红/蓝锥桶，包括可见底座；多个桶分别画框 |
| 1 | blue_board | 蓝挡板主体，不含支架；启动和停车处同类，由任务上下文区分 |
| 2 | traffic_light | 三灯及整个灯具外壳，不含大范围支架；亮/暗均标，灯态另行判断 |
| 3 | crosswalk | 同一横道全部可见白纸区域的紧外接框，不逐条标注 |

遮挡时框可见范围，出画时裁到图像边缘。不确定的内容待复核。二维码、停车区域不混入四类，后续独立实现。

每行 `class_id x_center y_center width height`，坐标归一化至 [0,1]，框必须在图像内。图与标签相同相对目录、同名主体。确认无四类目标时用空 `.txt`；缺少文件视作未标注。

按拍摄会话划分数据，大致 80%/20% 作为第一轮训练/验证起点，再按类别覆盖调整；另留全新测试视频。不能把相邻帧随机拆开。保存原图、标签版本、拍摄会话及来源。
