## 2026-10-07 Pi 5 键盘按住复核

新增显式 `--raised-held` 模式，用于完成旧 0.8 秒短测之后的架空复核。
只支持 Pi 5 的 RasAdapter S3/S4，按住方向键可续发已观察过的固定低油门，
每次按住最多 3 秒、启用后的整轮窗口 60 秒。每个续发电机段最多 200 毫秒；
控制消息仍在 200 毫秒失效，独立输出进程的 250 毫秒期限不变。
松开前进键即回零，空格急停及失联均锁定，普通心跳不能重新发车。
倒车保留 0.3 秒刹车和至少 1.2 秒零位等待，不提供调速。

此入口要求同一次开机的架空、电调关闭准备、30 秒基线，以及实际零油门、
转向、键盘停车观察；旧开机的测试记录不能直接启用。先使用原有有限
motor-only 短测补齐键盘停车观察，再准备按住模式。S1/S2 不被接管。
试验可单独保留暂定回正参考，自动驾驶配置与转向角完成标志保持原值。

该模式仅用于架空复核，未开放持续地面驾驶。2026-10-07 的自行重启及串口
超时原因仍未确认；复核通过不能据此宣称这些故障已经排除。

`serve_bench_drive.py` 在两路真实摄像头页面加入手动按钮，默认模拟模式。
普通 `carvision serve` 仍只有预览，不输出 GPIO。模拟模式会明确显示
“按钮不会驱动车轮”，可以先检查键盘、按住/松开、急停与控制超时。

## 使用范围

这是已确认原配硬件的短时架空测试入口，不是落地驾驶或比赛运行入口。
不更改 `pi-control.json` 的完整校准状态，不猜最大油门，不修改电池类型。

- BCM13：零油门1500微秒；前进1575微秒，最多0.8秒。
- 倒车只使用已观察成功的1300微秒序列：0.3秒、连续零位1.2秒、0.8秒。
- BCM12：左1750、正中1650、右1550微秒，以10微秒/20毫秒渐变。
- 云台BCM17/27保持不动，不在这里做供电负载测试。
- 必须按住按钮/方向键；长按不会重复短测，全部松开后才能重新触发。
- 松键、切出窗口、关闭页面发送停车请求；控制消息200毫秒过期后锁定。
- 超时或急停后，普通控制消息不能恢复动作；需要解除急停并重新启用。
- 每段电机波形有限周期，后接零位；停车主动取消波形队列。
- 实车进程最长120秒，独立外层150秒期限；结束关闭信号、恢复输入并记录。

网页按住前进/W/↑，倒车/S/↓，左/A/←，右/D/→；空格是急停。
模拟/实车状态会醒目显示。启用实车短测前，必须确认车轮架空、电调打开后
静止且已就绪、开关在手边；启用后先保持12秒连续零油门。

## 启动

在交付根目录、摄像头未被另一个进程占用时：

```sh
PYTHONPATH=vision/src .venv/bin/python vision/tools/serve_bench_drive.py
```

电脑与树莓派通过现有网线连接，打开 `http://树莓派地址:8080/`。
这个默认命令不连接GPIO，使用真实摄像头，控制部分为模拟。

实车运行要求电调先关闭、当前人工架空准备确认、当前启动标识和新的记录
目录，再显式传入 `--run --bench-prepared --expected-boot-id ... --output ...`。
硬件由独立系统Python进程控制；它自行检查控制消息时限，摄像头环境无需
安装lgpio。转向复用本机已测试的PCM/DMA驱动，只允许BCM12；电调复用
校验固定哈希的 `/home/pi/motor_test.py` 类，只允许上述有限波形。

只供当前可信局域网使用，不提供公网用户认证。控制POST需要当前页面的
随机控制键，并拒绝跨来源请求；同一时刻只有一个页面拥有控制权。
软件停车及有限波形不是物理断电装置，电调开关仍需在操作者手边。

### 供电调整接线计划

保持整车断电。可以共用原动力电池，但树莓派与舵机需要独立稳压支路。
树莓派4B使用合格USB-C 5V/3A级供电；现有降压板实际能力尚未核实。
三个舵机采用独立5V稳压电源/BEC。建议为多个舵机预留电流余量，
选择标明连续输出8–10A的规格；这是容量规划，不是对现有板子的认证。
BEC输入额定范围必须覆盖电池实际电压，20Ah容量不能确定电压。

| 导线 | 连接位置 |
|---|---|
| 三个舵机红线 | 独立5V电源正极，移离树莓派5V针脚 |
| 三个舵机黑/棕线 | 独立电源负极 |
| 独立电源负极 | 树莓派GND物理39针，共地 |
| 转向信号线 | BCM12 / 物理32针 |
| 云台左右信号线 | BCM17 / 物理11针 |
| 云台上下信号线 | BCM27 / 物理13针 |
| 电调白色信号线 | BCM13 / 物理33针 |
| 电调黑色地线 | 现有树莓派GND连接 |
| 电调红色BEC线 | 继续单独绝缘，待实际输出规格核实 |

独立舵机电源正极不并入树莓派5V排针；电池正极不直接接舵机。
确认电源输出和极性后，先只给树莓派上电、保持电调关闭，复核静态供电，
再逐个舵机短测，最后验证驱动轮及停车保护。未完成前不做落地驾驶。

依据：Raspberry Pi官方硬件文档（Pi4B供电及欠压检测），
https://www.raspberrypi.com/documentation/computers/raspberry-pi.html
