# S3 实时 PWM 调试：已集成版（2026-10-08）

适用当前 Pi 5 + RasAdapter5A。已合并提供的 PWM v1 功能，并保留原 5G 持续遥控。
不需要另起相机、UART 或网页进程。双击桌面“智能车5G测试”，使用同一个控制页。

## 使用

1. 结束正在进行的测试。网页点击“结束当前测试，返回模式选择”，等待清理完成。
2. 电调关闭，车轮架空。选择“仅 S3 转向调试（电调关闭）”。
3. 勾选现场确认，点击“准备 S3 调试”。约 30–45 秒检查供电、开机和 5G；不打开 UART，不写 S4/S3/S1/S2。
4. 电调继续关闭，手移开车轮和转向机构，再勾选确认并点击“启用 S3 调试”。此时才创建只拥有 S3 的工作进程，并发送原中位；等待 1 秒。
5. 拖动滑条、填写整数，或点 ±1/±5 μs。范围 1550–1750 μs；调节即开始试调。也可点“试调当前值”。
6. 每次最多 2 秒，更新目标不会延长这次时间；结束回原中位。点击“停止试调并回正”可提前结束。
7. 可反复试调；本轮 120 秒正常结束后，保持电调关闭、勾选架空确认并“开始下一轮”。
8. 调试完成后结束当前测试，选择“5G 持续遥控”，按该模式的电调关闭/打开步骤重新准备。

## 数值与边界

- 显示目标请求值、已下发值和原中位。已下发是软件提交记录，不是实测转角；没有舵机位置传感器反馈。
- 当前暂定中位为 1610 μs：2026-10-08 用户要求从 1615 μs 改为 1610 μs 继续测试。1610 μs 同时用于持续遥控的直行保持、松键回正和 S3 试调结束回正，仍需低速直行验证。1550 的临时端点中位试调标志保持关闭；输出范围仍是 1550–1750 μs，A 目标 1750 与中位相差 140 μs，D 目标 1550 与中位相差 60 μs，这些差值不代表实测车轮转角。
- 1662 μs 曾由用户报告目测前轮最正，早期参考为 1715 μs。滑条不会自动修改直行中位、键盘左右目标或正式标定文件。
- 找到车轮真正回正、左右转角合适的 PWM 后，记录这些值，再进行正式参数更新。
- 仅 S3 模式接受原始 PWM；持续行驶、S4、S1/S2 和暂停模式不能使用该接口。
- 空格或 Esc 急停、切出页面、失联、2 秒期限会停止试调并回原中位；当前页请求值不会跨模式自动重放。
- 保留 200 ms 输入期限和独立停车进程保护，不扩大已有机械范围。
- 代码和模拟浏览器已检查；新滑条在本车上的物理效果由现场确认。

## 离线预览

从工程根目录运行 `python tools/serve_pwm_demo.py`，打开 http://127.0.0.1:8931/。
页面明确标记模拟，不连接摄像头、UART、GPIO 或车辆。示例服务默认 10 分钟结束。
源码包包含当前网页、工作进程、驱动、配置及相关测试，应整体使用，避免只复制前端。
