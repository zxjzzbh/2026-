# 你现在需要做什么

优先让软件拿到真实画面；不用先完成 5G、IMU、STM32，也不用先学训练命令。

## 今天先做三件事

1. **将 USB 摄像头接到这台 Windows 电脑，确认能出图。** 固定在比赛允许的位置/视角；初稿禁止任意加高降低。未装车可先测出图，但素材标记为“非车载视角”。
2. **录第一批原始视频。** 保留原分辨率，不加字幕滤镜、不经聊天软件二次压缩。先交 10-20 段、每段约 20-40 秒可启动整理；这是首批建议，不是足够训练的保证。
3. **将原文件放进 `data/recordings/`，告诉我目录。** 每次拍摄单独文件夹，如 `day1-track-straight-01`；附天气、场景、是否装车/移动。不需要自己抽帧或调阈值。

在 `vision/` 打开 PowerShell：

```powershell
.\.venv\Scripts\python.exe -m carvision capture --camera 0 --seconds 30 --output ../data/recordings/day1-run1 --show
```

若不出图，提供错误文字及系统显示的相机名称。多相机时通过画面确认索引，必要时换 1；程序不会自动遍历或录制其他相机。

## 拍什么

| 场景 | 内容 |
|---|---|
| 白线 | 直道、左右弯；偏左、居中、偏右 |
| 光照 | 阳光、阴影、逆光，连续进出阴影 |
| 蓝挡板 | 放置、部分遮挡、移开完整过程及空场景 |
| 锥桶 | 初稿 8 cm 道具，红/蓝，远近、左中右、两个同时出现 |
| 红绿灯 | 实际灯具红/黄/绿/不亮状态，远近变化 |
| 斑马线 | 按初稿白纸尺寸与间隔，远到近 |
| 停车区 | 黄白线、两个入口分别被挡住 |
| 负样例 | 无目标、红蓝跑道、衣物、树叶、反光、普通虚线 |

不要求今天凑齐道具。先交白线、已有锥桶/挡板和空场景；缺少类别保持待采集。保留不同时间/光照拍摄的独立验证视频，不能把同一录像相邻帧拆分为训练/验证。

## 分工

- **我负责**：框架、抽帧、标签检查、训练/评估程序、导出、回放分析、失败样例、部署和联调代码。
- **你负责**：实物连接、原始数据、核对目标标签、按步骤做相机/实车测试。开始标注时先做少量示例供你核对；预标注也需复核，不能直接当真值。
- **队伍确认**：停车 3 秒/10 秒、设备资格、摄像头调整范围，以及实际车宽/轴距/机位尺寸。

主控已确认 Pi 4B + STM32 F4；F4 的具体型号/开发板留待确认。树莓派尚未准备好不阻塞电脑开发。准备后提供系统版本、位数、Python 版本与连接方式；密码不要写入公开仓库。
