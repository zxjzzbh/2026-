# v0.1 验证记录

日期：2026-09-23。验证平台为本台 Windows 11、Python 3.12.10、RTX 4050 Laptop（约 6 GB），不是树莓派。树莓派 4B + STM32 F4 尚未联机。

## 已验证

- 自动测试：17 项通过，覆盖偏差方向、丢边界、时序中断、未加载模型、灯态冲突、中文路径、回放与错误处理、数据标签和跨集重复。
- 合成录像回放：160 帧，140 帧正常双边界、20 帧主动移除双边界；20 帧均输出无效/null，而不是伪造零偏差。结果在 `outputs/demo-run/`。
- CUDA 可用：PyTorch 2.6.0+cu124、torchvision 0.21.0+cu124、Ultralytics 8.3.228。
- 官方 YOLOv8n 通用权重：下载校验记录见 `configs/model-source.json`；416 输入、3 次预热、20 次测量，在本机 GPU 对同一合成图片 predict 的 P50 约 18.7 ms、P95 约 20.8 ms。包含预测预后处理，不是整车帧率、Pi 性能或识别精度。
- 训练链路：使用 8 张训练、4 张验证的程序绘制图，运行 1 epoch，再将生成权重加载到四类感知接口。仅检验训练/保存/加载 API，不能用于比赛。权重存于 `outputs/yolo-smoke/`，有 `NOT_A_RACE_MODEL.txt` 标记。
- ONNX：上述测试权重导出为 416 输入、opset 19 的 ONNX，并经 CPU ONNX Runtime 成功加载运行。使用 onnx 1.17.0、onnxruntime 1.20.1。为保持已验证训练依赖组合，关闭可选图精简（simplify=False）。NCNN 尚未验证。
- `pip check` 无依赖冲突。

## 未验证与下一步

1. 外接摄像头已于同日完成 Windows 出图、三种尺寸、短时录制和回放测试，见 [相机测试记录](CAMERA_TEST_2026-09-23.md)。树莓派采集、曝光控制、光学标定和端到端延迟仍未验证。
2. 比赛四类模型在真实场景的误检/漏检；没有实拍数据，不能报告比赛准确率。
3. 白线基线、灯态在阴影/逆光/反光下的可靠性；当前未经过实景参数验证。
4. Pi 4B 的推理速度、功耗和持续运行；桌面指标不能替代。
5. F4 的具体型号、UART 电气/协议、停稳反馈及闭环；不提供猜测的引脚/PWM 参数。
6. 停车距离标定、挡板发车事件、任务状态机、绕桶路径和四轮入库判定；现有视觉输出不是完成这些任务的证据。

## 复现

在 `vision/` 下执行 `.venv/Scripts/python.exe -m pytest -q`。较重的可选 GPU 链路检查为 `.venv/Scripts/python.exe tests/smoke_yolo.py --output outputs/yolo-smoke-new --device 0`，它只使用合成图并明确标记产物。运行目录不得覆盖既有结果。

原始运行结果、下载权重、虚拟环境及合成训练产物均不进入 Git。参考资料未作为本队源码复制。
