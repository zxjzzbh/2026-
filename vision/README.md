# 视觉模块

负责将图片、录像或 USB 摄像头帧转换为可供主控使用的感知结果。当前只有目录说明，算法尚未实现。

## 放在这里

- `src/`：输入源、循迹、蓝挡板、斑马线、红绿灯、锥桶、停车和二维码画面处理。
- `configs/`：算法默认参数和相机配置示例；个人配置用 `*.local.json`。
- `tests/`：模块算法验证；少量共享样例放 [data/samples](../data/samples/README.md)。
- `requirements.txt`：完成环境验证后记录实际依赖。

这些子目录按首个实现按需创建；不要提交空壳“已完成功能”。参考 [视觉开发路线](../docs/vision-roadmap.md)。

## 输入与输出

输入为图像和时间信息，输出为车道边界、目标位置、有效性及质量指标。格式与单位在 [interfaces/](../interfaces/README.md) 共同确定。视觉不直接控制 PWM，不在检测函数里等待停车倒计时。

## 提交时补充

写明运行命令、Python/OpenCV 版本、使用素材、调试画面和误检/漏检情况。电脑结果不代替树莓派性能；未接摄像头就标明“仅离线验证”。不使用前辈完整程序作为本队原创实现。
