2026-10-05 实物确认使用幻尔 `RasAdapter5A V1.0` 拓展板。实际接线为 S1 云台左右、S2 云台上下、S3 转向、S4 电调。拓展板通过 `/dev/ttyAMA0`、1000000 波特率和带 CRC8 的串口协议控制，与 GPIO12/13 直连方式不同。`carvision.rasadapter5` 实现状态读取、受限制的 S3/S4 命令以及单独的 S1/S2 有限观察姿态测试；`tools/probe_rasadapter5.py` 读取的是控制器保存的输出值，不能据此判断插口上有没有舵机。I2C `0x40` 是此前的语音模块。

Pi 5 专用复测驱动 `carvision.pi5_pwm` 已接入原控制页，并根据复测记录选择实际串口后端。它独立记录本次开机的供电、零油门、转向和停车证据，不复用 Pi 4 的 DMA 实车通过记录。默认启动仍只显示预览。复测入口为 `tools/bench_pi5_neutral.py`，不加 `--run` 时仅检查；控制页实车模式须提供 `--pi5-review` 和明确的 `--motor-only`、`--steering-only` 或 `--combined` 范围。S1/S2 不参与本轮复测。准备窗口为 10 分钟，点击启用后开始 2 分钟实测；每次运动仍受原有短时限制。

Pi 5 地面短测通过 `--pi5-review --ground-short --ground-prepared` 单独启动，需要本次落地、空旷场地、电调关闭和开关可达的确认，以及已完成的零油门、转向、停车和失联停车验证。启用后测试窗口为 60 秒，最长单段运动设定为 0.8 秒，前进仍使用已在架空复测验证的 1575 微秒输出。2026-10-05 用户确认该轮低速、转向、倒车和停车正常，测试后电调关闭；供电标志为零且未重启，证据见 `../run/pi5-ground-20261005-01`。这轮只验证短时地面动作，尚未测量车速。全套 291 项软件测试通过。

GPIO 直连模式由 RP1 生成脉冲，拓展板模式由板载 MCU 生成脉冲。独立输出进程监测 250 ms 指令超时和最长 0.8 秒运动，并在控制进程退出后向 S4 发零油门、向已启用的 S3 发归中。拓展板可能在程序结束后保持这些输出；没有以未经文档验证的命令强行关闭所有通道。运动时限由软件监测，不是 Pi 4 的硬件有限 DMA 波形；输出进程被强杀、系统卡死或失电仍需物理断电处理。自动比赛配置继续保持未标定状态，地面持续行驶尚未开放。

已实现比赛状态机、米制观测接口、硬件 PWM 执行器、250 ms 指令超时归零、录音播放回执和人工扫码付款窗口。默认只预览或模拟，不输出运动信号。当前缺少真实比赛模型、距离标定和车速反馈连接，还不能直接完成实车自动驾驶。
