# 主控与车辆任务

负责树莓派上的整车入口、模式切换、任务状态机和高层控制。当前尚无运行程序。

## 放在这里

- `src/`：状态机、目标路径到运动指令的转换、模块调度。
- `adapters/`：视觉结果接收、通信模块接入、下位机串口适配。
- `configs/`：整车任务参数示例。
- `tests/`：使用模拟视觉/底盘消息验证任务切换。

## 约定

由此模块统一仲裁远程与自主控制权，其他模块不争抢执行机构。停车计时、播报、任务去重和命令失效处置放在此层。等待不能阻塞图像更新或连接状态处理。

与通信、视觉、下位机共同维护 [接口文档](../interfaces/README.md)。默认先跑模拟输入，不依赖 5G 或实车全部接通。

提交时提供状态转换图、启动/停止方法、模式切换和失效样例，并区分模拟验证、台架验证、实车验证。
