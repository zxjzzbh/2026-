## 怎么用

在车端源码根目录执行 `bash cpp/build.sh`，它会构建比赛程序并运行测试。需要 C++17 编译器、CMake、OpenCV 4 开发库，以及带开发头文件、NumPy 和 OpenCV 的 Python 3.10 或以上环境。

网页调试页选择“停车”进入停车单项，选择“全流程”从挡板发车开始。停车单项从停车区入口前的白线车道开始。点“开始测试”启动本轮，点“结束测试”终止。全流程在双桶通过并回中后切换到停车。更多配置见 [C++ 入口说明](cpp/README.md)。

在源码根目录用录像运行相同的程序：

```bash
bash cpp/run_debug.sh parking --video /path/to/H65.avi
bash cpp/run_race.sh --video /path/to/H65.avi --traffic-video /path/to/USB2.avi
```

停车使用 H65 地面相机的完整画面。全流程的红绿灯距离判定使用 USB2.0 主摄。双路回放须从同一时间起点开始。

## 停车如何接入本车

原包保存在 `cpp/algorithms/outdoor_parking_1618/`。组合程序取 H65 画面，按原包尺寸缩放至 352×288，调用原包的 `parking_controller`。原包导入的共享整车文件仅供其停车控制器使用。比赛锥桶入口在 `cpp/algorithms/hybrid.py`。

停车策略给出舵角和动力请求，组合程序交给本车 S3 串口执行器。转向中位从原车 1750 微秒映射到本车 1610 微秒，左右端点映射为 1870 和 1350 微秒。原车 12700 占空计数对应约 1588 微秒，本车从支持的 1570 微秒前进档起步，逐步增至请求值。原包的反向制动请求在本车使用 1400 微秒、0.25 秒，自中位起步且尚无前进输出时保持中位。前进指令对应的图像超过 0.25 秒则收油，停车策略保留原包默认 60 秒限时。

结束判定要求停车策略报完成并有当前停稳证据。这个信号不测量四轮与库线的实际位置。日志 `telemetry.jsonl` 的 `outdoor_parking_stage`、`outdoor_parking_side`、`outdoor_parking_reason` 分别记录阶段、选中库位和决策原因。
