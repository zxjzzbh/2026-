# 硬件与接线

存放型号清单、接线图、供电方案、安装尺寸、照片和标定记录。现有信息是开发基线，尚不是完整接线规范。

| 部件 | 已知信息 | 必须补全 |
|---|---|---|
| 主控 | 计划 Raspberry Pi 4B 8GB | 系统版本、供电与散热、参赛许可 |
| 摄像头 | WXSJ-H65HD USB 广角 | 采集模式、曝光支持、固定安装位置与标定 |
| IMU | WIT-Motion，VCC/GND/RXD/TXD | 具体型号、供电、串口电平、协议 |
| 通信模块 | 多 SMA 接口及 USB/UART | 型号、天线用途、供电、驱动和联网方式 |
| 动力 | 电机、ESC、散热风扇 | 型号、控制信号、制动/反转模式 |
| 电源 | 约 12 V 锂电池、DC-DC | 电池规格、实际输出、负载能力和连接图 |
| 下位机 | 计划 STM32 | 芯片、开发板、引脚和逻辑电平 |

建议按需建立 `wiring/`、`power/`、`mechanical/`、`calibration/`。照片应可辨认型号，并去除不必要的个人信息。接线表注明电压、地线关系、信号方向和确认来源，未知内容明确写“待确认”。

摄像头安装须遵守 [规则限制](../docs/rules/README.md)。不要将规则示例设备的规格当成现有未知模块的规格。
