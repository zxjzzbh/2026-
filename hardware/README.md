# 当前硬件基线

2026-10-09 补充：用户确认电调是火凤凰 **New Rain 480A 双向有刷电调**。用户已确认切至 **F/B（前进／刹车）**，实车制动能力与低速控制仍待验收，不根据型号名称或旧软件倒车策略推断。当前测试见 [主动制动说明](../vision/BRAKE_PARKING.md)；`vision/configs/parking-feedback.json` 保留尚未接通的闭环方案准备状态。

2026-10-08，依据新源码包及队伍确认更新。当前不使用独立 STM32。历史记录不代表此次已重新连接硬件。

| 部件 | 当前证据 | 仍待确认/验收 |
|---|---|---|
| 主控 | Raspberry Pi 5；review 记录 Model B Rev 1.0 | 本轮未读取系统/内存实物参数；供电重启根因仍未闭合 |
| 扩展板 | Hiwonder RasAdapter5A V1.0；`/dev/ttyAMA0`、1 Mbaud、CRC8 | 整机/串口失效后的硬件回退行为 |
| 执行口 | S1 云台左右、S2 云台上下、S3 转向、S4 ESC | 机械端点、实际转角及供电完整验收 |
| 双摄 | Sunplus 1bcf:2281、Microdia/H65 0c45:6368；by-id、640×480、MJPG 历史记录 | 室外持续性能、曝光与完整覆盖；不是深度摄像头证据 |
| 5G | 历史识别为 RM500U-CNV，NCM；有 NR5G-SA 短测记录 | 长程链路性能、失联组合测试 |
| 转向/ESC | 手动暂定中位 1715 us；ESC 1500 零位、1575 低速前进有历史记录 | 自主旧中位 1650 未同步定稿；右转机械复测、速度/制动标定 |
| 车辆几何 | 宽 0.30 m、轴距 0.245 m、轮距 0.24 m、车头至后轴 0.34 m | 动态误差与停车包络验证 |
| 地面映射 | 两路各自固定姿态、车头前 0.5-1.5 m；第二路 1600/1150 us | 不能外推到近场停车或整个视野 |
| 速度/定位 | 编码器接口和光流代码已预留 | 编码器型号、实际计数源、位姿来源均未完成验收 |
| IMU | 最初有 WIT 模块需求 | 本包未形成已验证 IMU 采集/融合链路，电平协议不猜测 |
| 播报 | I2C 0x40 TTS 或 WAV 后端 | TTS busy/idle 完成反馈 |

数值为本车记录，不能直接用于其他车辆。`vision/configs/autonomy-pi5.json` 保留未就绪状态。接线以 S1-S4 当前方案为准；Pi4 GPIO12/13/17/27 叙述是历史路径。比赛设备/机位许可仍需按规则核实。
