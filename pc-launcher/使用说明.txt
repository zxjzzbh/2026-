智能车 5G 一键测试

公开版首次配置：在 Windows 用户环境变量中添加 SMARTCAR_HOST，值为管理者提供的已授权树莓派 Tailscale 地址。
设置后重新登录 Windows，再双击入口；也可以在已设置该变量的新终端启动 start.cmd。
仓库不附带个人设备地址、登录密码或共享邀请。示例地址 smartcar.example.invalid 不能实际连接。

在本机双击 start.cmd。车辆开机并通过 5G 联网后，会自动打开控制页。
操作电脑只需能够联网，并与车辆处在已有的 Tailscale 网络中。
首次换电脑需要先安装 Python 3.10 或更新版本、Tk 界面组件和 Tailscale；不需要复制密码。
通常官方 Windows Python 安装包含 Tk 界面组件；换电脑时需要确认该组件可用。

网页步骤：
1. 电调关闭、车已落地、场地空旷且有人能立即断动力，勾选确认，点击“准备测试”。
2. 自动检查零油门、5G 网络及当前开机状态，约需 30～45 秒；这时保持电调关闭。
3. 页面提示后打开电调，驱动轮静止、手移开，勾选确认，点击“启用键盘测试”。
4. 等待 12 秒，点键盘操作区域，按住 W/S 前进和倒车，A/D 左右转向。
5. 上下左右方向键也可使用；W+A、W+D、S+A、S+D 可组合按下，支持持续控制。
6. 松开行驶键停车，松开转向键回正；空格或 Esc 急停。急停后解除并重新确认启用。

当前为固定低档位的 5G 长距离遥控，不设轮次、行驶总时长或单次按住时长限制。
倒车先执行刹车和回零等待，保持 S，准备完成后连续倒车；松键可取消。
松键、失联或切换窗口时停车，恢复网络不会自动恢复上次按键。
当前开机的倒车和长距离行驶效果由现场复测确认。
树莓派重启后重新走现场确认，不会开机自行行驶或恢复上轮按键。
电脑入口只在 127.0.0.1:18080 转发画面和新鲜请求，断开后不重放控制命令。
重复双击会复用已核对的本地转发并打开当前页面；不会强行关闭其他占用端口的程序。
连接等待上限 3 分钟；超时会给出提示，再次双击即可重新连接。

脚本不含密码，不要求 SSH 登录。树莓派的一键测试服务由首次部署安装。
如需查源码，电脑端入口为 oneclick.pyw；车端为 vision/tools/serve_boot_test.py。
