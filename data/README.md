# 数据与测试素材

Git 中保留少量可公开样例与 [数据索引](catalog.csv)。原始录像、大规模数据和运行结果放本地或团队约定存储。

| 位置 | 用途 | 是否提交 Git |
|---|---|---|
| [samples/](samples/README.md) | 少量可公开的小图片、短标注等回归输入 | 是，先检查大小和来源 |
| `raw/` | 原始采集数据 | 否，按需本地创建 |
| `recordings/` | 实车录像 | 否，按需本地创建 |
| `processed/` | 可再生成的处理结果 | 否，按需本地创建 |
| `catalog.csv` | 数据版本、来源、存储入口和用途 | 是 |

录像扩展名在根 `.gitignore` 中排除。不要把权重或视频改扩展名绕过忽略规则。确需跟踪大文件时由团队先约定存储方式。

数据索引字段：唯一标识、场景、来源、存储位置、校验值、用途划分、使用权限和备注；不确定填写 `待确认`。不要填密码、带临时令牌的下载链接或不可公开的个人路径。

训练、调参和评估按录制片段/场景分开，避免相邻帧跨集合。参考资料画面、合成图和本车实拍应分清来源。
