# 视觉开发路线

当前阶段：v0.1 离线感知底座已实现，外接摄像头已完成 [Windows 采集测试](../vision/CAMERA_TEST_2026-09-23.md)，树莓派上尚未测试，比赛模型尚未用实拍数据训练。硬件基线为树莓派 4B + STM32 F4。用户已确认 OpenCV + 轻量 YOLO 混合路线。详细资料核对见 [参考资料对照检查](../vision/REFERENCE_AUDIT.md)。

| 阶段 | 目标交付 | 当前状态 |
|---|---|---|
| 1 离线底座 | 图片/录像读取、叠加、结构化结果、配置、训练工具 | 已实现，软件测试通过 |
| 2 白线循迹 | 边界、中心路径、偏差、丢线状态 | 基线已实现，仅合成素材验证 |
| 3 蓝挡板 | 检测后确认存在与移开，输出一次启动事件 | YOLO 类别/存在性接口已接入，事件逻辑待实现，模型待训练 |
| 4 斑马线 | YOLO 区域候选、位置、一次通过事件；按数据比较条纹几何 | 类别接口已有；位置标定、去重及停车计时待实现 |
| 5 红绿灯 | 灯具定位、亮灯状态、未知状态 | 灯态候选实现，模型/实际灯具/停车区域未验证 |
| 6 红/蓝锥桶 | 多目标框、底部位置 | 框接口已有；比赛模型、底部点、距离及绕行待做 |
| 7 停车 | 黄白线区域、挡板入口归属、目标车位 | 未实现 |
| 8 扫码画面 | 二维码定位、清晰原图/裁剪输出 | 未实现专用模块 |

当前初稿是白色跑道边线、红/蓝小锥桶、蓝挡板选择空车位；不套用前辈的 A/B 标志分类流程。

已采用的路线是 OpenCV 车道几何 + 轻量 YOLO 元素检测。YOLOv8n 是首个训练/部署候选；四类为锥桶、蓝挡板、灯具、斑马线。通用预训练权重只验证环境与速度，不代替比赛微调。帧率和效果以 Pi 4B 实测与独立真实数据评估为准。

像素位置只有经过几何标定和实车验证才能解释成距离。斑马线停车还需要相机到车头的偏移、速度和制动距离；视觉检测成功不等于停车合格。

红绿灯区域不能只看图像下半部分；锥桶很小，二维码需要足够清晰度，处理分辨率要按任务实测。固定机位是否能同时覆盖这些目标需要摄像头测试。

采集素材时保留无目标、强光、阴影和失败片段。按不同录制片段划分调参和验收集；参考室内图片不替代室外实拍。每次结果记录设备、参数、素材版本与处理耗时。

API 参考：[OpenCV HSV 分割](https://docs.opencv.org/4.x/da/d97/tutorial_threshold_inRange.html)、[相机标定](https://docs.opencv.org/4.x/dc/dbb/tutorial_py_calibration.html)。
