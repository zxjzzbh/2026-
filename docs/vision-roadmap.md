# 当前视觉路线

2026-10-08：已完成离线框架、USB 双摄预览、白线和颜色/形状检测基线、YOLO 流程以及静态地面映射；不再处于“摄像头未测试”的初始阶段。

下一步优先级：

1. 建立斑马线从远处可见到车头前 25 cm 的连续可信距离，处理接近后丢失；现有最近标定 50 cm 不足。
2. 建立停车框稳定坐标与位姿跟踪，解决近边退出视野后四轮位置估计；验证红/蓝跑道。
3. 选定传统或比赛专用模型的感知部署路径，按场景独立划分数据，量测漏检/误检/确认延迟。
4. 补充动态标定验证、完整道路覆盖、曝光/振动/光照、小锥桶与无目标负样例。
5. 为斑马线、红绿灯、锥桶和停车分别给出真实验收，再接完整任务。

视觉框线、软件测试、静态映射和实车任务通过是四类不同证据。现有经典检测器仍是 experimental 状态；自主链路要求已验收检测器，不能靠改状态字符串授权运动。技术细节和复现见 [审查](reviews/2026-10-08-source-review.md)。
