更新日期：2026-10-20。包含 PR #7 的目录整理和 PR #6 的停车路径更新，原停车部署记录截至 10 月 14 日。本次完成合并检查及离线测试，没有连接、部署或重新测试小车。软件在主线、曾经部署、实车验收通过是三个不同状态。

## 当前基线

- **代码**：主线已整合 Pi5/5G 遥控基础、双摄、比赛分项、完整流程、独立视觉停车试验与米制路径入库。最新固定源码为 [source-2026-10-20-r2](latest-code.md)。
- **硬件**：Raspberry Pi 5 + RasAdapter5A UART；S1/S2 云台、S3 转向、S4 ESC；双 USB 摄像头。不使用独立 STM32。
- **常用入口**：`connect-car.cmd` → 本机 `127.0.0.1:8082`；另一套 `pc-launcher/start.cmd` 使用 `18080`。分别见 [指南](guides/README.md)，两者均依赖已有车端服务。
- **转向**：现行共享常量为右 1350、中位 1610、左 1870 μs；旧自主配置、独立 PWM 调试范围及历史标定分别保留，见 [标定索引](calibration-status.md)。
- **验收结论**：完整自主赛道未通过；停车实际停点、四轮入位与多个运动标定项仍待验证。

## 版本和验证记录怎么读

2026-10-20，PR #6 与整理后主线合并候选的本地结果为 **1698 通过、3 跳过**。跳过项为 Windows 不支持的 Unix socket/termios 检查。检查范围、命令和已知基线问题见 [PR #6 检查记录](reviews/2026-10-20-pr6-review.md)；GitHub 两平台检查结果以 PR/发布页为准。

原作者10月14日停车部署记录说明：保留车端遥控和现场配置，增加约40 ms独立控制续期，慢识别和日志写盘不占控制锁。车端30秒静态回放使用模拟执行器，没有打开UART；实际入位尚未验收。Git 主线提交不能直接证明今天车端运行的版本。

路径模式在后端核验近场映射、当前转向半径、实测速度/曲率表和位姿反馈；默认13项缺口仍阻止启用。视觉对照模式要求有效双侧白线，丢失后有限制动并锁定停止；两种模式不会自动互相降级。

详细证据与过程保留在 [原开发及部署记录](history/development-through-20261013.md)、[PR #6 停车开发记录](history/2026-10-14-parking-path.md)；原视觉说明的增量日志保留在 [视觉开发记录](history/vision-development-through-20261013.md)。
