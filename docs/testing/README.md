# 测试与联调记录

每次有结论的实验保存为 `YYYY-MM-DD-模块-主题.md`，可从 [实验模板](../templates/experiment.md) 复制。当前已有源码包附带的历史核验/标定 JSON，见根目录 run/；原始完整录像/日志未全部随包交付。本次离线核验见 [2026-10-08 审查](../reviews/2026-10-08-source-review.md)。

记录至少包含代码 commit、硬件型号、环境、配置、数据索引、步骤、预期结果、实测结果和仍未覆盖内容。使用“通过/失败/未测试”分别标记，不用“应该能跑”代替结果。

大日志、原始视频不入 Git，放数据索引；文档中引用脱敏摘要和必要小图片。软件、台架、实车结果分开标记，不能相互替代。
