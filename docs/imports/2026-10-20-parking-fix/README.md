## 本包变化

| 内容 | 行为 |
| --- | --- |
| 边界判断 | 当前有效白线优先；连续新鲜、空闲且图像包络合适的同一车位可补充短暂缺线，危险边界否决补充 |
| 暂停与结束 | 证据不足时有限制动并等待；边界恢复且取得有效停稳反馈才继续，持续不足则锁定退出 |
| 对齐修正 | 同一车位的连续新鲜证据允许受控反向修正，默认最多越过中位80 μs，仍受速率及边界限制 |
| 运行时限 | 默认寻位5秒、总入位30秒；初始化和结束制动另计，重新选区不重置总时限 |
| 末段输出 | 默认末段上限1550 μs，服从更低的前进设置；准备时同时冻结前进/末段档位 |
| 停车参考 | 网页可分别设置图像减速线/停止线；留空采用明确标为未验证迁移的历史图像参考 |

新增 `parking_visual.py` 集中验证视觉停车选项，附新增回归及三次历史失败输入。米制路径模式、遥控、光流修复和原有物理验证标志不因此变为已验收。
