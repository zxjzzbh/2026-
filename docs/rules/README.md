## 队伍现场确认与仍待核验事项

- **红绿灯为横排。** 队伍于 2026-11-14 明确确认，补充细则示意图的竖排绘制不符合实际道具。保留现有横排识别，不把该图作为增加竖排适配的依据。
- **硬件资格仍按指定清单核对。** 补充细则没有直接写“必须 Pi 4”；Pi 5、RasAdapter5A 和双 USB 相机的许可需以原规则 4.4 或组委会确认为准。
- **停车尺寸基准需与布场一致。** 当前程序将 1.5 m 解释为两条横向胶带外沿总长，胶带中心距 1.4 m、内沿净长 1.3 m。补充细则未明确内外沿口径，现场应核对，不能混用三种长度。

## 当前程序的比赛入口

使用 `vision/tools/run_race.py` 的正式入口。正式入口检查停车区 1.5 m、胶带宽度 0.1 m，并要求全部停车标定条件就绪；检查在释放遥控控制权之前执行。缺项时保持原控制状态，不启动不完整的比赛流程。

自主接管通过车端守护进程确认模式，停止依赖遥控网络，继续执行供电、温度与有限指令保护。断链后的完整赛道、停车四轮入位和远程付款仍需现场监护验收。

本地 `parking-bay.local.json` 优先于公共模板。迁移时核对真实场地，只修改已确认的规则尺寸，保留相机与运动实测数据；不得通过修改验证标志代替标定。历史数据使用对应历史配置回放。
